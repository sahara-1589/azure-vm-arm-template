# Azure Virtual Machine Deployment Using ARM Templates

## Overview
This project demonstrates Infrastructure as Code (IaC) using Azure Resource Manager (ARM) templates to deploy a fully functional Virtual Machine (VM) along with its required networking infrastructure in Microsoft Azure.

## Features
- Parameterized deployment
- Virtual Machine configuration
- Reusable infrastructure definition
- ARM template structure with parameters, variables, resources, and outputs

## Files
- azuredeploy.json
- README.md

## Learning Objectives

-Understand ARM template structure (parameters, variables, resources, outputs)
-Deploy Azure Virtual Machines using Infrastructure as Code
-Configure networking components (VNet, Subnet, NIC, Public IP, NSG)
-Apply parameterization for reusable deployments
-Use Azure CLI for deployment
Validate and troubleshoot deployments
Demonstrate secure VM provisioning
